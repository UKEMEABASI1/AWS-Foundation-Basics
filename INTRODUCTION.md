# Introduction to AWS Cloud Foundation Basic
---
## Welcome
Welcome to Level 1: AWS Cloud Foundation Basic. This programme is designed for learners who are new to cloud computing. You do not need to know how to code or have previous AWS experience. You do need basic computer literacy, curiosity and a willingness to practise.

The course starts with everyday examples: storing files online, accessing websites, using email and connecting devices. We use those examples to explain how organisations rent computing, storage and networking services instead of buying and maintaining every server themselves.
## What is cloud computing?
Cloud computing is the on-demand delivery of technology resources—such as computing power, storage, databases and networking—over the internet, usually with usage-based pricing.

Think of electricity: most homes do not build a power station. They connect to a provider and pay according to use. Cloud computing offers a similar model for IT resources, although customers remain responsible for how they configure and use many services.

## Why learn AWS?

Amazon Web Services (AWS) is a major cloud platform. It offers services for hosting applications, storing files, managing networks, databases, identity, monitoring and much more. Learning AWS fundamentals helps learners understand the building blocks used by cloud, infrastructure, DevOps and software teams.

## How we will learn

This course combines:
- Plain-language explanations before technical terms
- Instructor demonstrations
- Guided AWS console labs
- Small individual and group projects
- Weekly review and troubleshooting
- A final website deployment

Every practical lesson follows a repeatable pattern: **Plan → Build → Test → Explain → Clean up**.

---
## What this course does not assume

Learners are not expected to be software developers, network engineers or Linux administrators. We introduce only the command-line and networking concepts required for the labs. Advanced automation, Terraform, containers, CI/CD, high availability and production architecture belong in later training.

## Learner responsibilities

- Attend and participate in all three weekly sessions.
- Ask questions when a term or instruction is unclear.
- Follow account and cost-safety instructions.
- Keep a learning journal.
- Never share credentials.
- Submit evidence of work without exposing secrets.
- Clean up resources at the end of each lab.
---
## A note about AWS costs

AWS is a paid cloud platform. Some accounts may qualify for Free Tier offers, but eligibility, limits and pricing vary and can change. A resource can incur charges even when a learner believes it is idle. Therefore After every lab session, learners must cleanup or terminate every resources being created, to avoid incurring unnecessary costs.

## Where this course leads

Graduates who meet the learning outcomes can progress to Level 2 — Intermediate AWS Cloud Engineering, where they can study more detailed VPC design, routing, load balancing, scalable compute, databases, infrastructure as code, monitoring and deployment workflows.
