# Eight-Week / 24-Session Schedule

| Week | Day 1 | Day 2 | Day 3 |
|---|---|---|---|
| 1 | What is cloud computing? | Cloud models | Cloud use cases and diagrams |
| 2 | AWS and console | Root user and MFA | IAM foundations |
| 3 | Regions | Availability Zones | Edge locations and service scope |
| 4 | IP, DNS and ports | VPC and subnets | Internet gateway and security groups |
| 5 | Compute and EC2 | Launch EC2 | Connect, inspect and clean up |
| 6 | S3 buckets and objects | S3 access and protection | Database and RDS foundations |
| 7 | Shared responsibility | CloudWatch | Budgets and cleanup |
| 8 | Prepare website | Deploy S3 website | Test, present and clean up |

Recommended pace: three sessions per week, approximately 2–3 hours per session. Include breaks and allow additional practice time for learners who are completely new to IT.
