# Course Outline
This document outlines the course structure, session format, required equipment, and core AWS services and concepts for the training programme.

---
## Programme structure

| Week | Theme | Day 1 | Day 2 | Day 3 | Weekly deliverable |
|---|---|---|---|---|---|
| 1 | Cloud fundamentals | What is cloud? | Cloud models and service models | Cloud use cases and diagrams | Draw and explain a simple cloud solution |
| 2 | AWS account and IAM | AWS account and console | Root user, MFA and IAM | Users, groups, roles and policies | Secure-account checklist and IAM scenario |
| 3 | AWS global infrastructure | Regions and AZs | Edge locations and service scope | Console navigation and region selection | Region/AZ research card |
| 4 | Networking fundamentals | IP, DNS and ports | VPC, subnet and route table | Internet gateway and security group concepts | Draw a basic VPC network |
| 5 | Compute services | EC2 concepts | Launch and connect to EC2 | Inspect, secure and clean up EC2 | Basic EC2 web-server demonstration |
| 6 | Storage and databases | S3 buckets and objects | S3 permissions and lifecycle concepts | Database fundamentals and RDS overview | Organise and secure an S3 bucket |
| 7 | Security, monitoring and cost | Shared responsibility and least privilege | CloudWatch basics and logs | Budgets, billing awareness and cleanup | Cost/security review checklist |
| 8 | Website deployment and review | Website files and S3 hosting plan | Deploy static website | Test, present and clean up | Live static website capstone |

## Session format

Suggested 2–3 hours per session:
1. Welcome and recap — 10 minutes
2. Lesson and vocabulary — 30–45 minutes
3. Instructor demonstration — 20–30 minutes
4. Student lab — 45–60 minutes
5. Review, questions and cleanup — 15–20 minutes

## Required learner equipment

- Laptop or desktop with a supported browser
- Reliable internet access
- Text editor
- AWS account approved for training
- MFA-capable phone or authenticator
- Notebook or digital learning journal

## Core AWS services and concepts

- AWS Management Console
- IAM
- Regions and Availability Zones
- VPC, subnet, route table, internet gateway, security group
- EC2
- S3
- RDS as an introductory database service
- CloudWatch
- AWS Budgets and billing tools
